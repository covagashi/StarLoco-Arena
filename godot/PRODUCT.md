# Native client surfaces

This Godot 4.7.1 client reimplements DofusArena 2.70. The lobby is the shell after coach creation/login and on return from fights; there are no worlds to walk (the owner chose a lobby with PvE/PvP leagues). Every screen outside combat is a native Godot panel; the XULOR2 layer stays only as the event router and model the native panels reuse. Existing protocol handlers remain authoritative.

Every screen outside combat is native (S18, closed 2026-10-20) and, since 2026-10-24, in the stone-and-gold style of the retail-coloured fight HUD (`src/ui/ui_style.gd`, `DESIGN.md`); the owner dropped the 1-bit look, in fights and screens alike. The old Pillow-baked stone family, the retail XML dialogs and the debug panes (`ElementDlg`, the debug strip and its dialogs) are gone. The authored viewport is 1280×720. Mount the shell inside the UI CanvasLayer; retain chat and keyboard focus. Retail services that were places (graveyard, totems, firework launcher) live where a current game would put them: the fallen in Team, tournaments in the Calendar, the demon offering in the clan tab, fireworks on the lobby sky.

Lobby actions follow retail order: training, ranked fight, random search, evolution, duo, team. Menus retain retail ordering and logical dialog names; native factories resolve those names. Every panel must close by mouse and Escape without requiring its menu button. Coach appearance and identity come from the shared localCoach model, populated from State. Display unavailable information honestly; never invent server data.
